## How We Work

<details>
<summary style="font-size:16px; font-weight:600; color:#c97b9c; cursor:pointer;">Contributing to our projects</summary>
<br/>

We welcome all contributions — even typo fixes count. Just make sure it builds and doesn't break anything.

**Development workflow:**
- Fork and clone the repository
- Create a feature branch with a descriptive name
- Make your changes and commit with clear messages
- Push and open a pull request

</details>

<details>
<summary style="font-size:16px; font-weight:600; color:#c97b9c; cursor:pointer;">Project structure</summary>
<br/>

```
LATstudio-WeFun/
  .github/
    workflows/
      snake.yml          # Contribution snake auto-generation
  README.md              # This file
```

</details>

<details>
<summary style="font-size:16px; font-weight:600; color:#c97b9c; cursor:pointer;">Tech philosophy</summary>
<br/>

We pick the right language for the job, not the one with the best marketing.
- Need speed and async I/O? Node.js
- Need data processing and ML? Python
- Need to keep a legacy service alive? PHP
- Need a simple script? Shell

No framework wars. No language purity tests. Just working software.

</details>
